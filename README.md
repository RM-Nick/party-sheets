# Party Sheets

Mobile character sheets for Amber, Mäusfänger and Mamuk (D&D 2024 rules), with a shared Party page, live dice feed and portraits.

- Live site: https://rm-nick.github.io/party-sheets/
- Data: Supabase project `party-sheets` (ref lpbjlnjjlfxdtlcdvvhs). Tables `docs` and `rolls`, storage bucket `portraits`. Row level security allows signed-in users only, and sign-ups are disabled, so only the shared party login can read or write.
- `index.html` is generated by `src/assemble_site.py` from the files in `src/`.

Rules text: System Reference Document 5.2 by Wizards of the Coast LLC, licensed under CC-BY-4.0. Entries outside the SRD are short summaries written for this app, with links to 5e.tools.
